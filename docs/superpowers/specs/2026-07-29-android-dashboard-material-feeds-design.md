# 安卓看板刷新与材料流设计

## 目标

精简安卓 H5 的今日、市场、赛道和标的看板，让各页聚焦最有用的信息：

- 今日看板支持页面级下拉刷新。
- 市场热度排行榜支持市场、赛道和标的切换，默认查看 7 天。
- 赛道和标的看板改为可持续浏览的最新材料流。

本次复用现有接口和共享下拉刷新组件，不修改后端、数据库或业务计算。

## 今日看板

使用已有 `PullToRefresh` 包裹今日看板内容。页面位于顶部并下拉超过既定阈值后，同时刷新：

- `GET /api/console/workbench-today`
- `GET /api/reports?offset=0&limit=4`

刷新只作用于今日看板，不影响其他看板查询。刷新期间保留现有内容；任一请求失败时显示共享组件的失败反馈。

## 市场看板

排行榜类型控制器调整为：

- 市场：`type=all`
- 赛道：`type=track`
- 标的：`type=stock`

时间控制器保持 `24h / 7d / 30d`，默认值从 `24h` 改为 `7d`。初始查询键和请求参数为：

```ts
["market-rankings", "all", "7d"]
```

不修改排行榜卡片位置、底部控制器布局、错误重试或空数据状态。

## 赛道材料流

删除以下内容：

- 升温赛道指标
- 重点赛道指标
- 赛道热度卡片

页面只保留“最新材料”，使用：

```http
GET /api/track-discovery/materials?limit=10&offset=<offset>
```

材料按现有后端顺序展示。首屏 10 条，滚动到列表底部后自动请求下一页。

每条材料显示：

- 赛道名称
- 方向标签
- 材料标题
- 最多两行摘要
- 来源
- 材料时间

## 标的材料流

删除以下内容：

- 标的池指标
- 重点标的指标
- 评分排行卡片

页面只保留“最新材料”，使用：

```http
GET /api/stock-analysis/materials?limit=10&offset=<offset>
```

首屏 10 条，滚动到列表底部后自动请求下一页。

每条材料显示：

- 标的名称和代码
- 方向标签
- 材料标题
- 最多两行摘要
- 来源
- 材料时间

## 共享材料组件

新增业务展示组件，将赛道和标的接口数据转换成统一的材料视图模型：

```ts
type DashboardMaterialItem = {
  id: number;
  entityName: string;
  entityCode?: string | null;
  direction?: string | null;
  title?: string | null;
  summary?: string | null;
  sourceName?: string | null;
  materialTime?: string | null;
};
```

共享组件只负责材料卡片、方向标签和列表状态，不负责请求。赛道页和标的页分别维护自己的无限查询键和 API 调用。

方向映射统一为：

- `support`：利好，红色
- `weaken`：利空，绿色
- `neutral`：中性，灰色
- `noise` 或缺失：不显示标签

标的接口使用 `impact_direction`，赛道接口使用 `direction`，在页面数据映射阶段统一到 `direction`。

## 自动加载

新增共享的列表底部观察哨兵，使用 `IntersectionObserver`：

- 每页固定 10 条。
- 下一页 `offset` 等于已加载条数。
- 仅当 `has_more=true` 且当前未加载时请求下一页。
- 观察哨兵重复进入视口时不会并发请求。
- 下一页失败时保留已有材料，底部显示重试按钮。
- 没有更多数据时显示“没有更多材料”。
- 空列表显示“暂无最新材料”。
- 初次加载失败使用整页材料卡片内的错误重试状态。

如果运行环境不支持 `IntersectionObserver`，底部显示“加载更多”按钮作为回退，不自动请求。

顶部下拉刷新和底部自动加载是不同交互。本次只有今日看板新增顶部下拉刷新；赛道、标的和市场看板不增加顶部下拉刷新。

## 样式

- 材料卡片采用连续列表和细分隔线，不增加阴影或渐变。
- 实体名称与方向标签同一行；长名称和代码允许省略。
- 标题保持清晰层级，摘要最多两行。
- 来源与时间使用次要文字颜色。
- 利好沿用红色语义，利空沿用绿色语义，中性使用灰色。
- 兼容浅色、深色和跟随系统主题。
- 在 320px、360px、407px 和 412px 视口保持无横向溢出。

## 接口与类型

前端新增：

```ts
trackMaterials(offset = 0, limit = 10): Promise<PageDto<TrackMaterial>>
stockMaterials(offset = 0, limit = 10): Promise<PageDto<StockMaterial>>
```

市场排行类型扩展为：

```ts
type MarketRankingType = "all" | "track" | "stock";
```

后端接口和返回协议保持不变。

## 测试

- 验证今日看板下拉一次只刷新今日工作台和最新报告。
- 验证市场默认请求为 `type=all&window=7d`，三个类型选项映射正确。
- 验证赛道页只显示最新材料，不再出现旧指标和赛道热度。
- 验证标的页只显示最新材料，不再出现旧指标和评分排行。
- 验证赛道和标的材料基本信息、方向标签、缺失字段回退。
- 验证观察哨兵加载下一页、阻止并发请求、失败重试和无更多状态。
- 验证不支持 `IntersectionObserver` 时显示手动加载按钮。
- 运行安卓 H5 全量测试、TypeScript 检查、生产构建和 `git diff --check`。
- 在 320px、360px、407px、412px 及明暗主题下进行真实浏览器检查。

## 非目标

- 不为市场、赛道或标的看板增加顶部下拉刷新。
- 不修改 Web 看板。
- 不修改后端、数据库、材料排序或材料状态规则。
- 不增加材料筛选器、搜索、详情跳转或新的业务操作。
