# 安卓组合标的热力图设计

## 目标

在安卓 H5 看板的“组合”页中，于“标的组合”环图卡片下方增加“标的热力图”矩形树状图，帮助用户快速比较持仓结构和当日表现。保持现有组合选择、刷新、排序和缓存行为不变。

## 页面与视觉

- 页面顺序为：组合选择 → 今日表现 → 标的组合 → 标的热力图 → 四项资产指标。
- 热力图使用现有 ECharts，通过 `treemap` 系列实现，不增加图表依赖。
- 每个矩形代表一个标的，面积使用持仓市值 `market_value`。
- 矩形内部按可用空间显示标的名称、现价和今日涨跌幅：
  - 空间充足时显示三行。
  - 空间有限时优先显示名称和涨跌幅。
  - 极小矩形只显示名称；完整数据通过 ECharts 提示框查看。
- 上涨使用克制的红色阶、下跌使用绿色阶、平盘或缺失行情使用中性色；文字保持足够对比度，明暗主题分别使用适配色值。
- 图表高度为 `240px`，禁用缩放、拖动漫游和层级下钻，避免与移动端页面横滑冲突。
- 图表容器增加 `data-swipe-ignore="true"`，触控操作不触发看板分页。

## 数据与接口

- 继续使用 `GET /api/portfolios/overview`，不新增接口、不修改数据库。
- `allocation_rows` 与 `pie_items` 的标的项新增：
  - `current_price: number | null`
  - `quote_time: string | null`
- 继续复用已有 `stock_id`、`stock_code`、`label`、`market_value`、`weight` 和 `day_pct`。
- 单组合模式直接返回持仓现价及报价时间。
- “全部组合”模式继续按 `stock_id` 合并相同标的；聚合市值和涨跌保持现有算法，现价取该标的非空报价中 `quote_time` 最新的一项。
- 缺失现价或涨跌幅时显示 `--`，不把缺失行情当作平盘。
- 环图和热力图使用同一份 `pie_items`，随组合选择和刷新同步更新。

## 组件边界与状态

- 在安卓 H5 图表组件中新增独立的 `PortfolioTreemap`，只负责把组合标的数据转换为 ECharts treemap 配置并处理主题。
- `DashboardPage` 负责数据获取、空状态和组件装载，不在页面内实现矩形布局算法。
- 无标的数据时不渲染空图表，显示“暂无标的热力图数据”。
- 图表懒加载失败或数据请求失败时，继续沿用组合概览现有错误与重试行为。
- 刷新按钮仍位于“标的组合”卡片；一次刷新同时更新环图、列表和热力图，不增加重复刷新入口。

## 验证

- 后端单元测试验证单组合返回现价，以及全部组合按最新 `quote_time` 选择现价。
- 安卓组件测试验证数据映射、红涨绿跌、缺失值回退和三行标签内容。
- 页面测试验证“标的组合 → 标的热力图 → 总市值”的 DOM 顺序，并确认组合切换共用同一概览数据。
- 样式测试锁定 `240px` 高度、横滑隔离和窄屏无横向溢出。
- 在 `320px`、`360px`、`407px` 和 `412px` CSS 宽度下检查明暗主题、文字裁剪和触控行为。
- 运行相关非破坏性后端测试、Android H5 全量测试、TypeScript 检查、生产构建和 `git diff --check`；不运行任何会清空或修改数据库的测试。
