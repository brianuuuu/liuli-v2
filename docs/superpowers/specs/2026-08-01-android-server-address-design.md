# 安卓“我的”服务器地址与榜单位次文案设计

## 目标

- 将市场热度排行榜指标名称由“升降位次”改为“位次变化”，保留 `+3`、`-2`、`--`、`new` 及现有颜色语义。
- 优化“我的 → 应用 → 服务器地址”为展示和编辑两个明确状态。

## 交互与布局

- 默认状态与上下设置项保持同一行高，左侧以普通字重显示“服务地址”，右侧显示当前实际地址；不显示服务器图标、粗体标题或编辑箭头。当前地址取页面正在使用的 `window.location.origin`，地址过长时单行省略；点击地址行进入编辑。
- 编辑状态左侧仍显示“服务地址”，将当前地址带入右侧输入框，并显示固定宽度、禁止换行的“保存”按钮。地址为空或与当前地址相同时禁用保存。
- 保存时去除首尾空白并继续调用现有 `nativeBridge.setServer()`；原生外壳负责持久化、规范化和重新加载，不新增桥接接口。
- 普通状态与编辑状态保持 48px 以上触控高度，在 320px 至 412px 视口不产生横向溢出，并兼容现有明暗主题变量。

## 范围

- 仅修改安卓 H5 页面、样式和测试。
- 不修改原生服务器存储、后端 API、数据库、榜单排序或数值算法。

## 验证

- 集成测试验证默认地址、点击编辑、保存参数和“位次变化”文案。
- 样式测试验证地址省略、固定保存按钮宽度和横排文字。
- 运行安卓 H5 全量测试、TypeScript 检查、生产构建及 `git diff --check`。
