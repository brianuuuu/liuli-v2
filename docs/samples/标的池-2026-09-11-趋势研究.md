# 标的池趋势研究（2026-09-11）

> 本文件是**趋势研究报告的格式样例**，用于固定字段契约与回归导入链路，不是真实研究结论。

## 字段契约

- 标题格式 `研究对象-YYYY-MM-DD-趋势研究`。第一段只是人类可读的范围标签，不参与业务解析——
  `安克创新-…`、`标的池-…`、`AI算力-…` 在导入端走完全相同的路径。
- 末尾最终 JSON **永远是数组**。单标的报告就是长度 1 的数组，所以没有单份与批量的分支。
- 每个元素对应一条 `stock_trend_snapshot`，字段名与表字段一一对应。
- 标的身份：优先给 `stock_id`；没有时给 `company_code` 由导入端反查。两者都缺或都查不到，这一条算失败。
- 赛道给 `main_track` 名称，不给 `track_id`。名称匹配上 `track.name` 就填 `track_id`，
  匹配不上只留文本，不报错也不新建赛道。
- `stock_id`、`track_id`、`report_id` 由导入端填，报告不需要提供后两者。
- 必填只有标的身份、`research_date`、`trend_level`，其余字段缺失按 null 落库。
- 硬校验三条：`trend_level` ∈ `T0`~`T5`；`suggested_group` 给了就必须是
  `focused/candidate/watching/archived`；`research_date` 必须等于标题日期。
- 导入按部分成功处理：返回成功与失败条数及失败明细，有一条成功即算成功并把回流状态置为 `parsed`。
  快照表没有唯一键，同一天允许多份，所以重复导入会产生重复记录。
